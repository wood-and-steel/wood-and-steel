## Out-of-date statements in the existing docs

Found while writing. `Game rules.md` has since been replaced by [RULES_AGENT_GUIDE.md](../RULES_AGENT_GUIDE.md), so the entries about it are history.

- **`Game rules.md`, Set Up:** "make a note they have $10,000 cash and $0 debt" on paper, and "switch to the Contracts tab". The app tracks money now, and Home is the only page.
- **`Game rules.md`, App:** describes a Railroads tab. It's now the "Acquire a railroad" step of Actions.
- **`Game rules.md`, Regional Office:** "additional contract… (Not yet implemented)". It is implemented (`generatePrivateContractSpecs` in `src/Contract.ts`).
- **`src/rules/playerBoard.ts`:** the John Bull's effect reads "Must be traded in for the American", and the printed player board says "Cover this space with the 4-4-0 American". The clarified rule (2026-11-09) and the app let you keep the John Bull.
- **`Game rules.md`, Upgraded Stations and Timetable:** "Run a Train action", "Run Trains action" and "Run trains" are all used. The book uses **Run Trains**.

## Choices that change wording, not rules

- **Actions are named as the app's Actions sheet names them**, in title case: "Acquire a railroad" appears as Acquire an Independent Railroad (the full name) with the app label in the callout; "Discard and draw new contract" became **Discard and Draw a New Contract**.
- **Movement and building are counted in Routes**, since the map prints Routes and their prices, not lengths. A Route's length only sets its price, which is printed.
- **Build costs are taught from the printed price**, not the length table, because the board already prints each Route's price, doubled for Mountain Routes. The length table is still correct: printed price + $1,000 parallel (+ $2,000 Mountain) matches it.
- **"Independent Railroads never take a Mountain Route printed $10,000 or more"** restates "mountainous routes of length 4 or more" in terms players can see on the board.
- **The 1⅓× bonus** never actually needs rounding: every Contract is worth a multiple of $3,000. The rounding rule is kept anyway.
- **Bankruptcy, the West Coast bonus, Go First and connection bonuses** are listed as in development, not taught, because the app doesn't support them.

## Review checklist (guide §14)

**Teaching flow**
- [x] The first page states the premise, win condition and loop. Game length is open (Q1).
- [x] No rule is used before it's explained; forward links where needed (Debt Service from Money, Upgrades from Actions).
- [x] Turn steps are numbered and each Action links to its section.
- [x] A first game can be set up and played from sections 1–7.
- [ ] Optional modules: none yet. Rules in development are listed, not taught.

**Clarity**
- [x] Every Action follows the same pattern: flavor line, Cost, "This Action lets you…", sub-rules, Example, In the App, See also.
- [x] Every Action has a worked example except Borrow Money, Discard and Draw (one-line rules) and Buy an Upgrade (its examples are under each Upgrade).
- [x] Timing: Free Actions say when they're allowed (your turn, during Actions) and when they aren't (other players' turns).
- [x] Each rule is stated in one place; the Quick Reference repeats numbers only.
- [x] Rule sentences are second person and active; flavor lines are italic and set apart.

**Consistency**
- [x] Capitalized terms are bolded once where defined and listed in the Glossary.
- [ ] One synonym remains on components and in the app: Route/segment (Q11).
- [ ] Icons: the book has no icon key yet; the board's commodity icons need one (add when final art exists).
- [x] Numbers match `src/rules/rulesData.ts`, the Quick Reference, and the app.

**Reference**
- [x] Cross-references use section names with links. **Page numbers** must be added at layout and then checked against the Contents.
- [x] Fine Print covers precedence (playtest), who tracks what, hidden information, fixed words, limits and mistakes. Tiebreakers are open (Q2).
- [ ] The Q&A should be extended with questions from real playtests.
- [x] Glossary and Index exist.
- [x] The Quick Reference covers turn, Actions and costs, Free Actions, track, delivery, Engines, Upgrades, end of round and scoring.
